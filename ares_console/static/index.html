Radio (Hamlib rigctld)
      
      
      
      
      
-m is the Hamlib rig model (rigctld -l lists them), -r the CAT serial port, -s its baud rate. If JS8Call also controls the radio, set JS8Call's rig to "Hamlib NET rigctl" at 127.0.0.1:4532 so both can share it.

    

    
Winlink / ARDOP
      
      
      
      
      
      
Linux: to pick the radio's sound card, put PULSE_SOURCE=<input name> PULSE_SINK=<output name> in front (names from pactl list short sources / sinks). Windows: ardopcf {port} <input #> <output #>.
